# Dataset Privacy Notice

The original dataset used for this project is **confidential and is not included in this public GitHub repository**.

The project may use customer, order, payment, and transaction-level information in an authorized local environment. Those source files must remain outside version control.

## Public repository contains

- Python/Pandas data-preparation logic
- SQL Server/T-SQL analytical queries
- Data-quality and validation logic
- Documentation
- Non-sensitive project-level KPI definitions

## Public repository does not contain

- Raw CSV files
- Excel exports
- Customer-level records
- Personally identifiable information
- Payment details
- Company source-system extracts
- Credentials or secrets

If the project is reproduced locally, place authorized source files in this directory and ensure `.gitignore` excludes them before committing.
